# etalii.adp.ide.eclipse

[![Build](https://github.com/etalii-adp/etalii.adp.ide.eclipse/actions/workflows/build.yml/badge.svg?branch=develop)](https://github.com/etalii-adp/etalii.adp.ide.eclipse/actions/workflows/build.yml?query=branch%3Adevelop)

The ADP designers as an Eclipse plug-in. There is no plug-in code yet; once there is, the Build workflow offers the plug-in's update site as a download from each run.

ADP, A Different Perspective, is a range of task-focused diagram and text designers. The site is at <https://etalii.net/adp/>.
